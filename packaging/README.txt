TimeTracker — Windows 10/11 x64

1. Распакуйте всю папку TimeTracker в постоянное место, например D:\Apps\TimeTracker.
   Не переносите TimeTracker.exe отдельно от _internal.
2. Запустите TimeTracker.exe. Значок часов появится в трее.
3. В меню трея выберите «Открыть dashboard» или откройте http://127.0.0.1:6969/.
4. Для автозапуска включите «Запускать вместе с Windows» в меню трея.
   Для отключения снимите эту отметку. По умолчанию автозапуск выключен.
5. «Выход» в трее завершает запись, закрывает сессии и локальный сервер.

Python, Node.js и интернет для работы не нужны.
История: %LOCALAPPDATA%\TimeTracker\tracker.db
Журнал: %LOCALAPPDATA%\TimeTracker\logs\tracker.log
Данные сохраняются отдельно от приложения и остаются при обновлении файлов.

Если порт занят: TimeTracker.exe --api-port 8766
Для отдельной истории: TimeTracker.exe --database D:\MyHistory\tracker.db
Перед обновлением выйдите через трей. После переноса папки заново включите
автозапуск в меню: в Windows хранится абсолютный путь к программе.

В «Настройки сбора» доступны обычный режим и экономичный режим ETW.
Для ETW нажмите «Установить и выбрать экономичный режим», подтвердите запрос
администратора Windows, дождитесь завершения и перезапустите приложение.
При дальнейших запусках, включая автозапуск, подтверждение не требуется.
Для отключения ETW выберите обычный режим и перезапустите приложение.
Фоновый компонент можно удалить отдельно из настроек; история сохраняется.
Перед обновлением компонента выберите обычный режим и перезапустите приложение,
затем нажмите «Обновить / восстановить компонент». Полный пакет должен содержать
папку collector\TimeTrackerETW вместе с её _internal; не переносите её EXE отдельно.
При недоступности ETW запись продолжается через обычный опрос.
Один экономичный экземпляр приложения на пользователя Windows.

Расширенная вкладка и пауза записи пока недоступны в MVP.
Сон, блокировка и idle собираются автоматически. Статистика обновляется при
смене фильтров и по кнопке со стрелками; периодического обновления нет.
