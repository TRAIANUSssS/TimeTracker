# Проверки TimeTracker

Здесь будут тесты по разделу 36 технического ТЗ. Сейчас создан каркас проекта;
тестов бизнес-логики ещё нет.

Порядок добавления:

1. Состояния и интервалы: процессы, foreground, IDLE/LOCKED/SLEEP, recovery.
2. SQLite: миграции, транзакции, ограничения и статистические запросы на временной БД.
3. API: фильтры, пустые состояния, PATCH и обработка невалидных параметров.
4. Интеграция с Windows: отдельные проверки адаптеров и ручные сценарии сна/блокировки.

Domain-тесты используют fake providers и управляемые часы; Windows API им не нужен.
SQLite-файлы тестов создаются в `tmp_path`, без обращения к пользовательской истории.

После добавления тестов запуск из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest
```

Пока тестов нет, pytest завершится с кодом 5 (`no tests collected`).
Проверки текущего каркаса перечислены в корневом README.
