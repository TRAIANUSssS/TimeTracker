# Web-интерфейс TimeTracker

Каталог для desktop dashboard по [UI-спецификации](../time_tracker_ui_spec.md).

Frontend пока не реализован. Framework, сборщик и зависимости добавим на этапе UI;
Node.js сейчас не требуется для запуска Python-каркаса.

Основные части будущего интерфейса:

- фильтры дат/времени, «Только активные», сброс и ручное обновление;
- общее активное время и таблица приложений;
- timeline одного дня и heatmap выбранного периода;
- заглушки расширенной статистики и настроек.

Контракты endpoints и расчёты задаёт [техническое ТЗ](../time_tracker_codex_spec_v2.md).
Компоненты, запросы API и frontend-тесты появятся вместе с реализацией интерфейса.
